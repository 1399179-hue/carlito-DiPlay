# DiPlay next release notes

## Steering wheel controls

- Identify steering wheel buttons and assign play/pause, next track, previous track, or Siri.
- Save settings by car and head unit model, apply them immediately, and upload them to the cloud. Uploads resume when the connection returns.
- Export saved settings or restore the original controls at any time.

## 方向盘按键

- 识别方向盘按键，设置播放/暂停、下一首、上一首或 Siri。
- 按车型和车机型号保存设置，保存后立即生效并上传云端；恢复联网后自动继续上传。
- 可导出已保存的设置，也可随时恢复原有按键功能。
